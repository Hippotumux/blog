我是中央大學數學系大三學生鐘仕翔，我對於數學和電腦科學充滿興趣。在大一上時，參加了演算法競賽培訓，成為校內競賽選手，並於大二大三參與 TOPC、NCPC、ICPC 等比賽。 大一下時加入 AI 讀書會，學習到很多機器學習和神經網路的知識。此外曾擔任程式競賽微課程講師、數學系程式檢定課程講師，目前為演算法課程助教，在教學的過程中也讓我對演算法和數學知識有更深的理解。

在系上，從大一開始在數學系的計中擔任了兩年的工讀生，並從大三開始擔任網管。學習方面，我對數學有著濃厚興趣，課外自學數論、啟發式算法、博弈論、組合數學和圖論等內容，養成了做筆記的習慣，至今在 HACKMD 上有著 288 筆記。在大三上跟著胡偉帆教授研究機器學習方法，並閱讀了幾篇相關論文如 Deep Learning: An Introduction for Applied Mathematicians、Kolmogorov-Arnold Networks、Denoising Diffusion Probabilistic Models 等。

此外，我擅長的領域有數學以及計算機:
- **數學領域**：數論、最佳化、數學分析、量子計算
- **計算機領域**：演算法、人工智慧、自然語言處理、神經網路

數學是我最熱愛的領域，喜歡動腦，享受和同儕間互相討論的氣氛。

## Learning Portfolio

### Foundations

大一時我參加了演算法競賽培訓，這段經歷對我來說像是挖到了一座寶藏。大學的演算法競賽範圍非常廣泛，不只是寫程式，還需要很多數學知識，像是數論、有限項多項式問題（如 FFT、NTT）、字串處理（如 KMP、Automata）、圖論和計算幾何。我發現很多問題可以透過數學轉換成更簡單的形式，而某些理論有著意想不到的應用，比如，快速冪的方法可以在 logN 複雜度下算出第 N 項費氏數列。這種「原來還可以這樣」的發現讓我覺得超有趣，這些經歷使我對於數學有更深一層的熱愛。

因緣際會下，我加入了系上的計中擔任工讀生，在這裡我認識到了許多優秀且熱心的學長姐。在此期間我透過虛擬機，學會了用 Docker 架設服務，如 Bot Music 使得聊天室可以撥放音樂、 架設 OnlineJudge 使我可以在數學系程式檢定課程提供學生練習。並且為了之後成為網管有足夠實力勝任，我於大二修了「計算機網路」，並向學長姐學習企業級網路管理技術，包括 Network-Attached Storage（NAS）、Intelligent Platform Management Interface（IPMI）、Network Address Translation（NAT）及動態 IP 配置（DHCP）。於大三成為網管後，架設了 GPU Server 以及 Ollama WebUI，提供學弟妹使用 Cuda 進行 GPU 加速運算和支援本地 LLM (Large Language Model) 的環境。

### Deepening My Knowledge

每周學長姊都會舉辦讀書會分享資工領域的知識，當時很常分享機器學習相關的知識，因此我自大一起便開始研讀，並在學長姊的推薦下加入了 AI 讀書會。抱持著滿腔熱忱，我開始透過線上課程，以及在讀書會上學習，並在修了數學系的「最佳化方法與應用」和「數值線性代數」後，開始漸漸理解機器學習背後的理論。

從 GPT 出世以來，我被這種技術深深震撼住，並於大三上時修了 Taiwan AI College Alliance 的 「自然語言處理」，幫助我了解整個自然語言處理的歷史脈絡以及各種技術，並於期末和兩位學生一同參加 Kaggle 上的 LLM Prompt Recovery 比賽。然在這次寒假參加台積電 TSMC 黑客松比賽，學會了用 LLM 搭配擷取增強生成 (RAG) 的技術來緩解 Hallucination 問題。

另一方面，我對於量子理論也充滿好奇，大學期間曾讀過「愛因斯坦萬物之理」、「最終理論」等科幻書籍，並參加學生量子數學年會，多次聆聽系上的學術演講，了解當前量子領域的發展與挑戰。為了更深入探索這個領域，今年選修了「量子資訊的數學基礎」，希望能從數學的角度理解量子基礎。

這些學習與研究的過程讓我累積了豐富的知識與實作經驗，我將自己的學習筆記與心得寫進了 Blog，分享給更多有興趣的人。

## Motivation and Future Works

因為興趣太多，其實很多時候並不能顧及到全面，導致有些科目的成績並不特別突出。有時候我也會懷疑自己是不是博而不精，甚至會想自己是不是走錯了路。但回頭看看這一路學習的過程，雖然不總是順遂，但確實讓我接觸到許多有趣的知識，也在嘗試與探索中找到了自己的方向。能夠一直堅持下去，除了對數學和演算法的熱愛，也多虧有朋友的陪伴與支持，讓我在迷惘時能繼續向前。這三年來的嘗試，讓我對自己的興趣和未來想踏入的領域有了更明確的方向。目前，我希望能繼續深入數學，學習機器學習與演算法，希望能進一步了解這個領域並於未來為世界做出貢獻。
